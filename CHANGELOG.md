# Changelog

All notable changes to Imprint Plays.

---

## [1.0.0] — 2026-08-01

### Added
- Initial release: 10 games playtested and approved
- `imprint-games` wrapper gear (v1.4) — loads manifest, presents menu, activates goofy mode
- `imprint-plays-manifest` (v1.3) — pure index of active games and retired games
- `plays-word-association` (v1.2) — 10 rounds + pit stop with banter
- `plays-two-truths` (v1.1) — user presents first, vault-powered lie detection
- `plays-would-you-rather` (v1.0) — vault-calibrated dilemmas, both options must be genuinely hard
- `plays-rank-these` (v1.0) — 5 items, chaos goblin lives in the gap
- `plays-aita` (v1.0) — ambiguous scenarios, natural language verdicts only
- `plays-desert-island` (v1.0) — 5 items, keep 3, the why is the game
- `plays-story-chain` (v1.0) — one sentence each, debrief only after
- `plays-guess-imprint-thinks` (v1.1) — confident wrong guess, correction is the fun
- `plays-young-name` (v1.0) — operator at age 8–12, ordinary moments
- `plays-mad-libs` (v1.0) — 5-minute sorbet game, snort-worthy by design

### Retired (never shipped)
- `plays-rapid-fire` — interrogation energy, no room for stories
- `plays-finish-the-sentence` — therapy vibes
- `plays-20-questions` — car game, too much work, no chaos goblin moments

---

## Versioning notes

Gear versions track independently from the repo version. A gear can be updated without bumping the repo version number — check individual gear frontmatter for gear-level changes.
